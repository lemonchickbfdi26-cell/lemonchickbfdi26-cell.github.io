СТРУКТУРА ПАПКИ ASSETS
======================

assets/img/    — картинки интерфейса
assets/video/  — видео (заставка и т.п.)
assets/fonts/  — шрифты, если будешь подключать свои

--- КАК ЗАМЕНИТЬ КАРТИНКУ ---

Имена файлов жёстко связаны с ключами в коде. Чтобы поменять обои:

1. Положи свой файл в assets/img/ под тем же именем, например wall_pink.webp
2. Если расширение другое (png/jpg/gif) — поправь его в index.html
   в объекте ASSET_EXT: "wall_pink": "png"

--- КАК ДОБАВИТЬ НОВЫЕ ОБОИ ---

1. Положи файл, например assets/img/wall_notebook.webp
2. В index.html добавь ключ в ASSET_EXT:      "wall_notebook": "webp"
3. Там же добавь ключ в массив WALLPAPER_KEYS — он задаёт порядок в галерее
4. В sw.js допиши путь в список SHELL, чтобы файл кэшировался офлайн

--- ВАЖНО ПРО КЭШ ---

После замены любого файла подними версию в sw.js:
  const CACHE = 'paper-mail-v2';  ->  'paper-mail-v3'
Иначе браузер продолжит показывать старую картинку из кэша.


--- ЗАСТАВКА ---

assets/video/splash-poster.webp  — статичный кадр, виден пока видео грузится
assets/video/splash.mp4          — сам ролик (положи сюда)
assets/video/splash.webm         — необязательный запасной формат

Логика в index.html, раздел "4. СПЛЭШ":
  SPLASH_MIN_MS = 1600  — минимальное время показа, чтобы не мигало
  SPLASH_MAX_MS = 6000  — потолок: если видео не загрузилось, уходим по нему

Заставка закрывается по одному из событий:
  1. видео доиграло до конца
  2. пользователь тапнул по экрану
  3. истёк SPLASH_MAX_MS

Требования к ролику:
  - вертикальный, примерно 9:16 (например 1080x1920)
  - БЕЗ звука: браузеры блокируют автозапуск со звуком
  - лучше уложиться в 3-5 секунд и 2-3 МБ, иначе первый запуск будет долгим
  - формат H.264 в mp4 — его понимают все мобильные браузеры

Если файла splash.mp4 нет — на экране просто останется постер.
Это нормальное поведение, приложение не сломается.


--- ФОНЫ ЭКРАНОВ ---

Положи в assets/img/ пять файлов:

  bg_auth.webp      — экран входа и регистрации
  bg_chats.webp     — список чатов
  bg_feed.webp      — публикации
  bg_settings.webp  — настройки
  bg_account.webp   — вкладка "Я"

Пока файла нет, экран просто остаётся обычным бумажным — ничего не ломается.
Можно выкладывать по одному и смотреть результат.

Размер: 1080x1920 (вертикаль 9:16). Меньше не надо — растянет и замылит.
Формат: webp качеством 80-85. Держи каждый файл в пределах 150 КБ,
иначе первая загрузка приложения станет заметно долгой.

Поверх каждой картинки лежит бумажная вуаль — иначе текст не читается.
Её плотность настраивается в index.html, раздел "4b. ФОНЫ ЭКРАНОВ":

  const SCREEN_BG_TINT = {
    bg_auth: 0.35,      // 0 - картинка как есть
    bg_chats: 0.62,     // 1 - сплошная бумага, картинки не видно
    ...
  };

Если картинка получилась контрастной и текст на ней теряется - подними число.
Если наоборот всё выцвело - опусти.

ВАЖНО: списки чатов и публикаций прокручиваются, а фон - нет.
Не рисуй важные детали по центру: их закроет контентом.
Работает нижняя треть и края.
